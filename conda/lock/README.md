# Explicit conda lock files

Generated by `make conda-lock`, named `<platform>-<blas>-<mpi>.lock`.

**These are checked in deliberately.** They are what CI consumes, so a
conda-forge migration cannot silently change a shipped artifact underneath us.
`conda/env/*.yml` is the human-readable spec; the lock is the authority.

`conda/bootstrap.sh` uses a lock when one exists for the requested
platform/BLAS/MPI combination, and falls back to solving from the spec
otherwise — so a new platform is never blocked on a lock existing first.
